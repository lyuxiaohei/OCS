  具体定级规则（系统自动）

  一条未回复待办的紧急度 = 时间梯度 和 类目梯度 取更高档：

  时间梯度（基于首次响应阈值 T，默认 5 分钟，复用已有超时配置）：
  - 等待 ≥ T → 紧急（临超时）
  - 等待 ≥ 60%·T → 较急
  - 否则 → 交给类目判定

  类目梯度（靠会话关键词/标签，复用后端已有规则引擎）：
  - 退款 / 退货 / 投诉 / 差评 / 破损 / 物流异常 →
  紧急（钱损·投诉风险，不论刚来多久）
  - 优惠券 / 订单异常 / 账户问题 → 较急
  - 积分 / 发票 / 发货时间 / 政策咨询 → 一般
