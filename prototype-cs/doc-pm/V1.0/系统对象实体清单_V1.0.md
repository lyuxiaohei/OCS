## 〇、全局约束

### 三层归属体系（所有运行态实体共用）

```
企业客户(租户 customer_id)
  └── 品牌商城(mall_id)
        └── 应用端/渠道(channel: 小程序 / H5 / PC / APP)
              └── 用户 / 会话 / 留言 / 评价 … 都挂在这一层
```

- 所有列表页支持按这三层筛选
- 数据隔离维度：`customer_id → mall_id → channel`
- 命名：文档统一称「应用端（渠道）」，字段用 `channel`

### 审计口径

| 动作发起方 | 代号 | source | 说明 |
|-----------|:----:|:------:|------|
| 终端用户 | C | 0 | 发消息/留言/评价 |
| 客服 | A | 1 | 接待/转接/撤回 |
| 客服主管 | S | 1（更高权限位） | 分配/审核/配置 |
| 系统 | SYSTEM | 2 | cron/WS/敏感词 |

> 任一状态迁移必须区分 S（人点）还是 SYSTEM（自动）。

### 1.1 会话 Session — 聚合根

**表**：`customer_chat_sessions`

#### 字段清单

| 字段名 | 中文名 | 类型 | 必填 | 校验/约束 | 来源 | 去向 | 说明 |
|--------|--------|------|:--:|----------|------|------|------|
| id | 会话ID | string | ✓ | 格式 `#CS` + 日期 + 序号 | 系统生成 | 全系统引用 | 唯一标识 |
| user_id | 用户ID | FK | ✓ | 关联 users 表 | 登录态 | 客户视图聚合 | — |
| customer_id | 企业客户ID | FK | ✓ | 租户隔离 | 会员库 | 筛选/隔离 | 三层归属根 |
| mall_id | 品牌商城ID | FK | ✓ | 父级 customer_id | 会员库 | 筛选/隔离 | — |
| channel | 应用端 | enum | ✓ | 小程序/H5/PC/APP | 前端上报 | 筛选/渠道统计 | 三层归属叶 |
| admin_id | 服务客服ID | FK | — | 关联 customer_admins，接入后写入 | 客服接入 | 归属/绩效统计 | 转接时变更，不重建会话 |
| entry_tag | 场景标签 | enum | ✓ | home/product/order/cart/help/profile/logistics/refund/phone | 前端按页面识别 | 工作台展示来源 | 客服无需用户复述 |
| context_params | 上下文参数 | json | — | product_id/order_id/tracking_no 等 | 当前页面数据 | 自动填充首条消息+卡片 | — |
| status | 会话状态 | enum | ✓ | wait/accept/pending/close/cancel | 状态机流转 | 列表筛选 + 标签 | 见状态机 §1.1a |
| pending_reason | 挂起原因 | string | — | status=pending 时必填 | A 手动填写 | 会话详情 | 如"等待用户提供凭证" |
| resume_at | 挂起恢复时间 | datetime | — | status=pending 时必填 | A 手动设置/系统默认 30 分钟 | cron 扫描 | 到期自动恢复 |
| created_at | 创建时间 | datetime | ✓ | 自动 | 系统 | 时长计算 | — |
| accepted_at | 接入时间 | datetime | — | status→accept 时写入 | 系统 | 响应时长统计 | — |
| resumed_at | 恢复时间 | datetime | — | status=pending→accept 时写入 | 系统 | 审计 | — |
| closed_at | 关闭时间 | datetime | — | status→close 时写入 | 系统 | 时长统计 | — |
| rating_status | 评价状态 | enum | — | pending/rated/skipped | 评价流程 | 待办聚合 | close 后生成 |

#### 状态机

```
[*] → wait（C发起咨询）
wait → accept（A接入/自动接入，乐观锁 CAS）
wait → cancel（C取消/排队超时，默认120s可配）
accept → pending（A挂起，设 resume_at）
pending → accept（resume_at到期/C发新消息/A手动恢复）
accept → close（A关闭/SYSTEM超时：无响应15分提醒 + 30分自动关闭）
close → [*]
cancel → [*]
```

**守卫**：
- `wait → accept`：乐观锁，多客服抢同一会话仅第一个成功
- `accept → close 自动`：pending 状态不计入超时；C 发新消息优先于定时恢复
- `cancel` 不生成评价任务

> 派生自会话，会话不重建，仅变更 admin_id

#### 字段清单

| 字段名 | 中文名 | 类型 | 必填 | 校验/约束 | 来源 | 去向 | 说明 |
|--------|--------|------|:--:|----------|------|------|------|
| id | 转接单ID | string | ✓ | 自增/UUID | 系统 | 转接记录 | — |
| session_id | 关联会话ID | FK | ✓ | + to_admin_id 唯一约束 | 发起时关联 | 会话详情-转接轨迹 | 防并发重复 |
| from_admin_id | 源客服ID | FK | ✓ | 发起者 | 当前会话 admin_id | 转接记录 | — |
| to_admin_id | 目标客服ID | FK | ✓ | + session_id 唯一约束 | A(source) 选择 | WS 推送目标 | — |
| reason | 转接原因 | enum | ✓ | VIP/技能不匹配/繁忙/超时 | A(source) 选择 | 原因标签 | — |
| reason_text | 原因备注 | text | — | 补充说明 | A(source) 输入 | 详情展示 | — |
| status | 转接状态 | enum | ✓ | pending/accepted/rejected/cancelled/timeout | 状态机 | 状态标签 + 倒计时 | 见状态机 |
| ttl_expire_at | TTL到期时间 | datetime | ✓ | created_at + TTL（默认5分钟，1~60可配） | 创建时计算 | cron 扫描 | 归零→回退 |
| accepted_at | 接受时间 | datetime | — | accepted 时写入 | 系统 | 审计 | — |
| rejected_at | 拒绝时间 | datetime | — | rejected 时写入 | 系统 | 审计 | — |
| created_at | 创建时间 | datetime | ✓ | 自动 | 系统 | 倒计时计算 | — |

#### 状态机

```
[*] → pending（A(source)发起 → WS 推送 user-transfer → TTL启动）
pending → accepted（A(target)接受 → 事务更新 sessions.admin_id + transfers.status）
pending → rejected（A(target)拒绝/满载自动拒）
pending → cancelled（A(source)取消）
pending → timeout（TTL归零 → SYSTEM 执行回退策略→目标回退/重新排队/取消）
```

**守卫**：
- 目标满载（`current >= max_sessions`）→ 卡片显示「满载」，不可选
- `session_id + to_admin_id` 唯一约束防并发重复
- 接受时事务原子性：同时改 `sessions.admin_id` 和 `transfers.status`
- 转接期间 source 只读不可发消息，C 侧提示「正在为您转接」

**强制约束**：
- `pending` 态不能直接回复（UI disabled + 后端校验）
- 60 秒冷却：同一 user_id 相似内容仅保留首条
- invalid 可撤销（回 pending），但 replied 不可逆

### 1.5 评价 Rating（含差评跟进）

**存储**：`customer_chat_messages`（type=rate）+ 差评跟进记录

> 评价本身是 Message，但差评有独立跟进子流程

#### 字段清单（评价数据部分）

| 字段名 | 中文名 | 类型 | 约束 | 说明 |
|--------|--------|------|------|------|
| rate | 综合评分 | int | 1-5 | type=rate 时存，≤2 判定差评 |
| rate_tags | 印象标签 | json | 多选 | 态度好/回复慢/未解决 等 10 个标签 |
| rate_comment | 文字评价 | text | ≤200字 | 选填 |
| attitude | 服务态度分 | int | 1-5 | 4维度之一 |
| speed | 响应速度分 | int | 1-5 | 4维度之一 |
| professional | 专业能力分 | int | 1-5 | 4维度之一 |
| solution | 解决问题分 | int | 1-5 | 4维度之一 |

#### 差评跟进状态机

```
会话 close → 待评价
待评价 → 已评价（C提交，rate≤2 触发差评预警→通知 S）
待评价 → 已跳过（C跳过/超时，sessionStorage 持久化）

差评(≤2星)
  → 差评已提交（SYSTEM 触发预警通知 S）
  → 处理中（S 介入回访用户）
  → 已解决（S 录入回访结果）
```

**守卫**：
- `cancel` 状态不生成评价任务
- 已跳过(completed/skipped)后本会话不再弹评价（`sessionStorage.cs_rating_status`）
- 超时阈值后自动归为已跳过

- 并发编辑：锁定机制，他人见「正在被 XX 编辑」，30 分钟无操作自动释放
- 驳回后必填原因；审核决定必选通过/驳回
- 上下线不需要再次审核

## 五、领域事件清单

> 用过去式命名，不可撤销，驱动后续流程。

| 事件 | 触发时机 | 后续动作 |
|------|----------|----------|
| `SessionCreated` | C 发起咨询 | 推送 wait 队列；触发欢迎语 |
| `SessionAccepted` | A 接入会话 | 推送 user-online；加载客户视图；清除排队 |
| `SessionSuspended` | A 挂起会话 | 暂停超时计时；会话移入挂起列表 |
| `SessionResumed` | pending 恢复 | 重新计入超时；A 收到提醒 |
| `SessionClosed` | 会话关闭(正常) | 下发评价卡片；归档；异步触发质检 |
| `SessionCancelled` | 会话取消 | 不生成评价任务 |
| `MessageSent` | 双向消息发送 | WS 推送对端；敏感词过滤；已读同步 |
| `MessageRecalled` | A 撤回消息 | 替换为撤回提示，2 分钟内 |
| `MessageModerated` | S 隐藏/脱敏 | 消息内容变更，触发器隐藏 |
| `TransferCreated` | A(source)发起转接 | WS 推送 user-transfer；TTL 启动 |
| `TransferAccepted` | A(target)接受 | 事务更新 sessions.admin_id；source 退出 |
| `TransferRejected` | A(target)拒绝 | 会话保持 source |
| `TransferTimedOut` | TTL 到期无响应 | SYSTEM 执行回退策略 |
| `RatingSubmitted` | C 提交评价 | 更新仪表盘均值；差评触发预警 |
| `RatingSkipped` | C 跳过/超时 | 不计入满意度分母 |
| `LeaveMessageSubmitted` | C 提交留言 | 60s 冷却启动；通知 S |
| `LeaveMessageAssigned` | S 分配处理人 | 锁定处理人；通知 |
| `LeaveMessageReplied` | S 发送回复 | 按渠道推送用户 |
| `LeaveMessageInvalidated` | S 标记无效 | 不计入考核统计 |
| `ArticleSubmitted` | 作者提交审核 | 进入审核队列 |
| `ArticlePublished` | 审核通过 | FAQ 列表同步更新 |
| `ArticleRejected` | 审核驳回 | 通知作者 |
| `SettingsChanged` | 保存系统设置 | 新参数对新会话生效 |

## 六、不变性约束（Invariants）— 不可违反

| 编号 | 约束 | 涉及实体 | 违反后果 |
|:----:|------|----------|----------|
| INV-01 | **留言必须先分配才能回复** | LeaveMessage | pending 态 reply 按钮 disabled + 后端 400 |
| INV-02 | **cancel 会话不生成评价** | Session → Rating | 脏数据计入分母 |
| INV-03 | **待处理态直接调回复接口必拒绝** | LeaveMessage | 绕过前端校验 |
| INV-04 | **消息撤回限 2 分钟内** | Message | `data-sent-ts` 判断，超时拒绝 |
| INV-05 | **60 秒内同 user 相似留言仅保留首条** | LeaveMessage | 重复刷留言 |
| INV-06 | **转接接受时 sessions.admin_id 和 transfers.status 同一事务** | Session + Transfer | 归属不一致 |
| INV-07 | **多客服抢同一 wait 会话仅第一个成功** | Session | 乐观锁 CAS |
| INV-08 | **敏感词库不可达时 fail-open 放行** | Message | 阻断正常消息（ADR-0008） |
| INV-09 | **pending 状态不计入无响应超时** | Session | 客服等用户补资料被误判超时 |
| INV-10 | **C 发新消息优先于定时恢复（pending → accept）** | Session | 用户行为优先于系统定时 |
| INV-11 | **to_admin_id + session_id 唯一约束防转接并发** | Transfer | 重复转接到同目标 |
| INV-12 | **坐席容量设为 0 该坐席不参与自动分配** | CustomerAdmin | 手动接入不受限 |
