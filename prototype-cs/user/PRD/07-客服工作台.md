## 1. 范围边界

### 1.1 本文档覆盖

客服工作台是全屏三栏页面（`admin-workbench.html`），属 P0 核心模块，覆盖以下功能域：

| 编号 | 区域 | 功能点 |
|------|------|--------|
| W-01 | 顶栏 | 客服状态切换、挂起/转接/备注/结束/待接受转接操作按钮、客户名/标签显示 |
| W-02 | 左侧会话列表 | 4 状态 Tab 切换、搜索过滤、会话项展示（头像/名称/渠道/最后消息/未读/状态标签）、右键菜单、超时/挂起视觉状态 |
| W-03 | 中间聊天区 | 消息收发、撤回/隐藏/脱敏、富媒体卡片（5 类）、图片发送、快捷回复面板、话术库抽屉、输入工具栏 |
| W-04 | 右侧客户信息 | 4 Tab（基础信息/行为数据/订单数据/服务数据）、订单时间范围切换 |
| W-05 | 弹窗/抽屉 | 挂起弹窗、转接弹窗、结束确认弹窗、备注下拉面板、待接受转接抽屉、话术库抽屉、卡片选择器 |
| W-06 | 全局交互 | 新消息弹窗+提示音双通道提醒、Toast 提示、侧边栏收起/展开 |

### 3.4 会话项状态标签

| Class | 含义 | 圆点颜色 |
|-------|------|----------|
| `.s-tag.waiting` | 等待 | 橙 |
| `.s-tag.urgent` | 紧急 | 红 |
| `.s-tag.transferred` | 转接入/已结束/已恢复 | 紫 |
| `.s-tag.pending` | 挂起 | 紫 |
| `.s-tag.warn` | 即将超时 | 黄 |
| `.s-tag.timeout` | 超时 | 红 |
| `.s-tag.rejected` | 转接被拒（会话已归还，待客服跟进） | 橙 |
| `.s-tag.transfer-timeout` | 转接超时（目标客服未响应，会话已回退） | 红 |
| `.s-tag.closed` | 已关闭 | 灰文字 |

> `.s-tag.rejected` 与 `.s-tag.transfer-timeout` 为转接结果状态标签，跟随会话状态持续存在，客服点击会话项不会清除；当客服对该会话执行实际操作（发消息/挂起/结束）使会话状态变化后，标签随之更新。

### 3.5 渠道标签

渠道标签在页面加载时由 JS 统一替换为 `.belong-line` 灰色小字（`var(--cs-text-tertiary)`），显示"品牌商城 · 应用端"格式，**不带任何渠道颜色**。

> 渠道归属三层模型见 ADR-0011。静态 HTML 中的 `.s-tag.channel` 仅作为占位，运行时被 `belong-line` 覆盖。

## 4. 中间 — 聊天区

### 4.1 功能用例

| 编号 | 角色 | 场景 | 动作 | 预期结果 |
|------|------|------|------|----------|
| UC-WM-01 | A | 发送文字 | 输入框输入 → Enter | 清空输入框；空内容（`.trim().length===0`）不发送；Shift+Enter 换行 |
| UC-WM-02 | A | 快捷回复 | 点「快捷回复 ▾」→ 选话术 | 面板 `#qrdd` 弹出（320px），含搜索框 `#qrSearch`；**分类已清空**（原售前/售后/物流/退款换货/通用结束 5 个分类及话术已移除），当前面板内无话术条目，待后台配置后再填充。点击话术（若有）写入输入框，面板关闭，输入框获焦 |
| UC-WM-03 | A | 话术库 | 点「话术库 ▾」→ 选话术 | 右侧滑入话术库抽屉 `#libDrawer`（460px），含搜索框 + 分类标签（全部/售前/售后/投诉/通用）+ 话术列表（含使用次数/最后使用时间）；点击条目填入输入框并关闭抽屉 |
| UC-WM-04 | A | 撤回客服消息 | hover 客服消息「⋯」→「撤回」 | **2 分钟内**：消息右上角显示「⋯」触发器 → 点开「撤回」→ 替换为「你撤回了一条消息」（配时钟图标 `.recall-icon`），触发器隐藏；**超 2 分钟**：消息右上角「⋯」触发器直接隐藏（无撤回入口）。**用户侧同步提示「客服撤回了一条消息」（双向，ADR-0006）** |
| UC-WM-05 | A | 发送富媒体卡片 | 点工具栏 6 按钮 | 见 §4.2 卡片类型详情 |
| UC-WM-06 | A | 发送图片 | 点「图片」按钮 | 触发隐藏 `<input type="file" accept="image/*">`，选文件后 FileReader 读取以 `<img>` 插入聊天区 |
| UC-WM-07 | A | 卡片弹窗详情 | 点卡片内按钮 | 根据卡片类型打开对应弹窗（订单详情/商品预览/物流详情/退款详情/购物车详情/FAQ 答案），见 §7.6 |
| UC-WM-08 | A | 新消息提醒 | 非焦点会话收到用户新消息 | 弹窗提示（昵称+消息预览+「立即查看」）+ 提示音；会话项未读徽标 +1。当前焦点会话仅徽标 +1 不弹窗（免打扰）；工作台非激活页签/最小化时弹窗+声音必达 |
| UC-WM-09 | A | 催办提醒 | 会话即将超时（首次响应/轮次响应/转接 TTL 之一接近阈值） | 系统主动推送结构化弹窗 + 提示音；弹窗 `persist=true` 不自动消失，客服点击「立即查看」跳转会话。**弹窗标题直接复用 admin-todo.html「即将超时」行的催办标题**，共 3 种枚举：① `首次响应超时 · {客户名}`（距首次响应阈值还剩 N，典型 1分20秒/阈值 见 admin-auto-reply）；② `轮次响应超时 · {客户名}`（用户消息已等待 N，阈值 3 分钟，典型 2分35秒）；③ `转接超时 · {客户名}`（转接【目标组】已等待 N，TTL 5 分钟，典型 1分05秒）。弹窗正文复用 `.nm-lines` 多行结构展示「等待时长/阈值 + 用户消息预览」。与 admin-todo.html 的区别：本场景为系统主动推送到工作台弹窗，待办页为客服主动点「催办」按钮 |

### 4.3 卡片状态色

| Class | 含义 | 颜色 | 典型场景 |
|-------|------|------|----------|
| `.s-warn` | 进行中/待处理 | 橙 | 待发货、运输中、审核中、推荐 |
| `.s-done` | 已完成 | 绿 | 已签收、已完成、在售 |
| `.s-danger` | 异常/售后 | 红 | 售后中、已退款、已取消 |

> 颜色仅表示状态，非卡片类型。状态映射函数 `stateCls()` 通过 `STATE_MAP` 字典（12 种映射）判定。三色系统与用户端聊天卡片完全一致。

### 4.4 消息操作按钮

| data-action | 文字 | 适用方 | 行为 |
|-------------|------|--------|------|
| `recall` | 撤回 | agent（客服消息） | 120 秒窗口校验，超时直接隐藏「⋯」触发器（无撤回入口） |

- 触发器 `.msg-actions-trigger`：hover 时显示，22px 圆形按钮
- 菜单 `.msg-actions-menu`：`.show` 状态显示
- 撤回后 `.msg-content.is-recalled`：触发器隐藏
- **用户消息无操作菜单**：客服工作台不对用户消息做隐藏/脱敏处理（无 `hide`/`redact` 操作）

### 5.1 功能用例

| UC-WR-01 | A | 切换信息 Tab | 点「基础信息/行为数据/订单数据/服务数据」 | 切换 `.info-pane` 显隐；active Tab 蓝色下划线 |
| UC-WR-02 | A | 查看基础信息 | 切换到基础信息 Tab | 显示客户卡片（头像/名称/ID/注册天数）、手机号（完整显示）、积分、归属（企业客户/品牌商城/应用端）、会员等级徽章；依次展示：积分信息（总积分/已消费/即将失效）、客户标签 `#custTagList`、客户备注 `#custNoteBox`（备注位于标签下方） |
| UC-WR-03 | A | 查看行为数据 | 切换到行为数据 Tab | 显示最近浏览记录（浏览/加购/收藏）、活跃度统计（近7天访问次数、平均停留时长） |
| UC-WR-04 | A | 查看订单数据 | 切换到订单数据 Tab | 显示订单概览统计（订单数/消费金额）+ 订单记录列表。含「近三个月/全部」时间范围切换，统计数字随切换变 |

> **消费金额统计口径（方案 A·实付金额）**
> 消费金额 = 所选时间范围内**全部订单的实付金额累计**，包含已完成、待发货、运输中、退款中、已取消等所有状态的订单。
> - 退款/取消订单的实付金额**计入**消费金额（反映客户累计交易规模）
> - 不额外扣减退款金额，不区分有效/无效消费
> - 客服可通过订单记录列表中的状态徽标（退款中/已取消显示红色）自行判断退款情况
> - 设计理由：消费金额用于识别客户价值（曾消费规模），而非净消费；退款/取消不影响"曾消费过"的事实
| UC-WR-05 | A | 切换订单时间范围 | 点「近三个月/全部」按钮 | 互斥选中 `.rt.active`；订单记录按 `data-range`（3m/all）显隐；统计卡数值切换 |
| UC-WR-06 | A | 查看服务数据 | 切换到服务数据 Tab | 显示累计咨询次数、本月咨询次数、满意度评价（星级 + 评分 4.8/5.0） |

## 8. 状态流转

### 8.1 会话状态机

| 对象 | 状态1 | → 状态2 | 触发 | 角色 | 守卫 |
|------|-------|---------|------|------|------|
| 会话 | — | wait | 用户发起咨询 | C | 无活跃会话 |
| 会话 | wait | accept | 客服接入 | A | 乐观锁（未被他人接入） |
| 会话 | accept | pending | 客服挂起（原因 + 恢复时间） | A | 暂停无响应超时 |
| 会话 | pending | accept | 恢复到期 / 用户发新消息 / 手动恢复 | SYSTEM/C/A | 恢复回原客服；恢复瞬间离线则重分（ADR-0009） |
| 会话 | accept/pending | close | 客服结束 / 用户超时 | A/SYSTEM | 结束即推评价邀请 |
| 会话 | wait | cancel | 用户取消 / 排队超时 | C/SYSTEM | — |

### 8.2 客服状态机

| 状态 | 接新会话 | toast 提示 | 徽章文案 |
|------|:------:|------|------|
| online（在线） | ✅ | 「已切换为「在线」，将正常接收新会话」 | 在线 |
| break（小休） | ❌ | 「已切换为「小休」，新会话将转给其他客服」 | 小休 MM:SS（每秒递增，切回其他状态即停止） |
| offline（离线） | ❌ | 「已切换为「离线」，不再接收新会话」 | 离线 |

> 小休/离线状态均不分配新客户给该客服，新会话自动转给其他在线客服。

## 10. 异常与边界

### 10.1 撤回边界

| 场景 | 处理 |
|------|------|
| 撤回时间戳缺省 | 无时间戳视为已超时，直接隐藏「⋯」触发器（无撤回入口）。后端须保证消息落库带 `sent_ts` |
| 超时撤回 | 超过 2 分钟（120 秒）的消息直接隐藏「⋯」触发器（无撤回入口，不再弹 alert） |
| 已撤回消息再次操作 | `.msg-content.is-recalled` 时隐藏 `.msg-actions-trigger` |

### 10.2 消息审核可见性（ADR-0006）

| 操作 | 客服侧 | 用户侧 | 原文留痕 |
|------|--------|--------|:------:|
| 客服撤回 | 「你撤回了一条消息」（气泡内替换 `.msg-recalled`） | 「客服撤回了一条消息」（居中灰条 `.msg-recalled-notice`） | ✅ |
| 用户撤回 | 「用户撤回了一条消息」（气泡内替换 `.msg-recalled`） | 「你撤回了一条消息」（居中灰条 `.msg-recalled-notice`） | ✅ |

> 双向可见：撤回是双向事件，操作方看「你撤回了一条消息」，对方看「X撤回了一条消息」。前端仅显示提示，不保留原文（符合微信/淘宝惯例），原文由后端保留。
> 客服侧展示形式统一为气泡内灰色斜体（`.msg-recalled`，保留消息在对话流中的位置，便于客服追溯上下文）；用户侧统一为居中灰条（`.msg-recalled-notice`，与时钟图标同款）。
> 客服工作台不提供「隐藏」「脱敏」操作，用户消息原文可见。如需敏感信息保护，由后端在落库或对外展示时统一处理。

### 10.3 转接边界（ADR-0003）

| 场景 | 处理 |
|------|------|
| 转接中态 | 源客服只读、不可发消息；用户侧提示「正在为您转接」；用户消息进队列 |
| 转接被拒 | 目标客服拒绝 → 会话项「转接入」标签替换为橙色「转接被拒」（`.s-tag.rejected`）→ 通知原客服（系统消息 + toast）→ 会话归还原客服。标签跟随会话状态存在，点击会话不清除 |
| 转接超时 | 目标客服超时未响应 → 会话项加红色「转接超时」（`.s-tag.transfer-timeout`）→ 通知原客服（系统消息「⏱ 转接超时 · 目标客服 N 分钟未响应，会话已回退给您」+ toast）→ 会话回退原客服。标签跟随会话状态存在 |
| 标签清除 | 「转接被拒」「转接超时」标签仅在会话状态发生变化时更新（客服发消息恢复沟通、挂起、结束等），不因点击会话项而清除 |
| 连环限深 | 限深 3 跳 |
| 失败回流 | 转接失败时队列用户消息退原客服、不丢 |
| 重新排队 | 累计 2 次终止兜底 |

### 10.4 挂起边界（ADR-0009）

| 场景 | 处理 |
|------|------|
| 挂起期间用户消息 | 不丢，恢复后送达 |
| 挂起期间客服离线 | 不触发离线宽限，仍按恢复时间走 |
| 恢复瞬间原客服离线 | 进重分 |

### 10.5 右栏联动边界

| 场景 | 处理 |
|------|------|
| 客户切换时 | 仅基础信息 Tab 随客户刷新；行为/交易/服务三栏恒显示默认客户 Mock |
| 全栏联动 | 属增量需求，一期不做 |

### 10.6 新消息提醒边界

| 场景 | 处理 |
|------|------|
| 当前焦点会话 | 仅徽标 +1，不弹窗不响（免打扰） |
| 非焦点会话 | 弹窗 + 提示音双通道 |
| 工作台非激活页签/窗口最小化 | 弹窗 + 声音必达 |
| 提示音开关 | 一期默认开，开关配置属增量 |
| 催办提醒（即将超时） | 系统主动推送结构化弹窗（`persist=true` 不自动消失）+ 提示音；不受焦点会话免打扰限制，必达。弹窗标题复用 admin-todo.html「即将超时」行的 3 种催办标题（首次响应超时/轮次响应超时/转接超时 · {客户名}），正文含等待时长/阈值/用户消息预览（`.nm-lines`），客服点击「立即查看」跳转该会话 |
