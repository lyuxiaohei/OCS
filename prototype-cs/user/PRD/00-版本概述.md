## 0 版本概述

V1.0 为 CS 商城客服系统用户端（小程序/H5）1期 MVP 全量功能，按原型一级菜单划分为4大模块：客服入口、聊天主界面、人工客服（排队等待/留言与离线反馈/服务评价）、FAQ机器人客服，共 11 个页面/组件。

### 0.2 核心功能

用户端客服系统为商城终端用户提供多渠道客服咨询能力：通过商城各页面嵌入的悬浮按钮/场景入口一键发起在线咨询或电话咨询，支持 entry_tag 场景透传自动携带商品/订单上下文；提供帮助中心FAQ自助服务；在线咨询支持排队等待、离线留言、富媒体卡片消息、会话内FAQ快捷问题等能力；会话结束后支持多维度服务评价。

### 0.3 数据来源说明

| 数据类型 | 来源 | 说明 |
|----------|------|------|
| 会话数据 | 本系统 `customer_chat_sessions` | 会话创建、状态流转、排队信息 |
| 消息数据 | 本系统 `customer_chat_messages` | 文本/图片/语音/卡片/评价消息 |
| 客服信息 | 本系统 `customer_admins` | 客服姓名、头像、在线状态、工号 |
| FAQ数据 | 本系统 `customer_chat_faqs` | 常见问题分类、内容、热度 |
| 商品数据 | 商城商品库 | 商品卡片展示信息 |
| 订单数据 | OMS/订单库 | 订单卡片展示信息 |
| 优惠券数据 | 商城营销系统 | 优惠券卡片展示信息 |
| 用户数据 | 本系统 `users` + 商城会员库 | 用户基础信息、会员等级 |

### 0.4 统计口径

| 指标 | 计算方式 | 示例 |
|------|----------|------|
| 排队等待时长 | 从进入排队到客服接通的时间差 | 02:30（2分30秒） |
| 满意度评分 | 评价消息4维度星级均分（1-5星） | 4.82/5.0 |
| FAQ热度 | 问题被查看/点击次数 | 2.3w |
| 预计等待时间 | 前面排队人数 × 平均服务时长 | 3人 × 50秒 = 02:30 |
