**字段定义**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | 文本(64) | ✅ | 规则名称 |
| match_type | 枚举 | ✅ | entry_tag（入口标签）/ user_attr（用户属性）/ keyword（关键词）/ fallback（兜底） |
| match_value | JSON | ✅ | 匹配条件值，如 `["mall_home","product_detail"]` |
| assign_type | 枚举 | ✅ | round_robin（轮询）/ idle_first（空闲优先）/ specified（指定客服）/ skill_group（技能组） |
| assign_value | JSON | 条件必填 | 指定客服ID列表 / 技能组ID |
| overflow_timeout | 整数 | 否 | 排队超时分钟数，默认 5 |
| overflow_action | 枚举 | 否 | transfer_all（转全客服）/ leave_message（发留言引导） |
| sort | 整数 | ✅ | 优先级排序，默认 0 |
| is_open | 布尔 | ✅ | 启用/关闭 |

**交互逻辑**：
1. 规则列表页支持拖拽排序调整优先级
2. 新建规则时，匹配方式和分配方式联动显示对应的条件字段
3. 兜底规则最多只能有 1 条，且不可删除只能编辑
4. 启用/关闭支持列表页直接切换

**字段定义**：

| 字段 | 类型 | 必填 | 说明 |

| level | 枚举 | ✅ | high（高）/ medium（中）/ low（低） |

**系统设置字段**：

| 字段 | 类型 | 说明 |

2. 支持单个添加和批量导入（文本粘贴 / CSV 文件）
3. 列表支持按分类和级别筛选
4. 删除敏感词需二次确认
