# 交互说明文档 — CS 商城客服系统交互原型

> 阶段：P06 原型设计 · 版本 V1.0 · 更新于 2026-06-11
> 上游依据：P01@V1.0 用户故事 · P02@V1.0 业务流程图 · P04@V1.0 竞品分析 · P05@V1.0 功能清单

---

## 概述

| 项 | 说明 |
|----|------|
| 原型覆盖 | **23 个逻辑页面**（用户端 8 + 管理端 12 + AI 端 3） |
| 物理文件 | 20 个独立 HTML + 1 个 `index.html` 导航页 + 1 个共享 `styles.css` |
| 设计风格 | 管理端 = Ant Design v5 风格（暗色侧栏 #001529 + 主色 #1677ff）<br>用户端 = 移动端聊天风格（375px 容器，微信绿 #95ec69 用户气泡 / 白色客服气泡）<br>AI 端 = 暗色看板（#141414 背景 + 渐变高亮） |
| 预览方式 | 浏览器打开 `prototype/index.html`，按端 / 期次分区点击卡片进入各页面 |
| 原型目录 | `prototype-cs/` |
| 期次标签 | `1期` = MVP 必交付（蓝色）· `2期` = 体验提升（绿色）· `3期` = AI 智能化（紫色） |

### 页面计数说明

用户端「场景咨询入口」`user-entry.html` 为单文件承载 **6 个商城页面场景**（首页 / 商品详情 / 订单详情 / 购物车 / 帮助中心 / 个人中心），每个场景视为独立交互页面，因此用户端逻辑页面 = 5 个独立文件场景 + 3 个补充页面，合计 8 个逻辑页面（聊天主界面、入口页、离线留言、服务评价、FAQ 列表，其中入口页含 6 子场景）。全文 23 个逻辑页面由此构成：8 + 12 + 3。

## 页面清单与交互说明

### 一、用户端（8 页）

#### U-01 聊天主界面

| 项 | 内容 |
|----|------|
| 页面路径 | `prototype/user-chat.html` |
| 功能描述 | 用户与客服（或 AI）进行实时沟通的核心聊天页，支持文字、图片、语音、视频、订单卡片、商品卡片、优惠券等富媒体消息收发 |
| 核心交互 | <ul><li>顶部标题栏显示客服名称 + 在线状态，点击返回箭头退回上一页</li><li>消息区按时间倒序展示气泡：用户消息靠右（绿底 #95ec69），客服消息靠左（白底），系统通知居中（半透明黑底）</li><li>底部输入区：文本输入框 + 「+」展开语音/相册/相机/位置/订单/商品 选择器</li><li>长按消息支持复制 / 删除 / 撤回（2 分钟内）</li><li>订单/商品/优惠券卡片内嵌消息流，点击卡片底部 CTA 按钮可跳转对应商城详情页</li><li>断线时顶部展示「网络已断开，正在重连…」横条，自动触发 WebSocket 重连</li><li>客服离线时自动转留言页（U-03）或触发 AI 兜底回复</li></ul> |
| 关联用户故事 | US-MVP-01 实时聊天 · US-MVP-12 富媒体消息 · US-MVP-13 订单卡片 · US-MVP-14 商品卡片 · US-MVP-15 优惠券卡片 · US-MVP-09 断线重连 |

#### U-02 场景咨询入口（含 6 个商城页面场景）

| 项 | 内容 |
|----|------|
| 页面路径 | `prototype/user-entry.html`（单文件含 6 场景卡片） |
| 功能描述 | 在商城 6 大核心页面（首页、商品详情、订单详情、购物车、帮助中心、个人中心）右下角嵌入统一悬浮「联系客服」按钮，点击进入会话并自动携带页面上下文 |
| 核心交互 | <ul><li>悬浮按钮带脉冲动画 + 红点未读提示，吸引用户点击</li><li>点击后前端读取当前页面 `entry_tag`（home / product / order / cart / help / profile）及上下文参数（product_id / order_id / cart_items[] 等）</li><li>跳转至 U-01 聊天主界面，自动发送带场景标签的首条消息 + 对应卡片（如商品页 → 自动发送商品卡片）</li><li>客服端在会话建立时即可看到用户来源场景，无需用户复述问题</li></ul> |
| 子场景清单 | <ul><li>**U-02-1 首页** `entry_tag: home` — 通用咨询入口，无附加参数</li><li>**U-02-2 商品详情** `entry_tag: product` + product_id / product_name / price — 尺码、库存、规格咨询</li><li>**U-02-3 订单详情** `entry_tag: order` + order_id / order_status / amount — 物流、催发货、退款</li><li>**U-02-4 购物车** `entry_tag: cart` + cart_items[] / total_amount — 凑单、优惠、满减</li><li>**U-02-5 帮助中心** `entry_tag: help` + faq_category — FAQ 兜底转人工</li><li>**U-02-6 个人中心** `entry_tag: profile` + member_level — 账户、会员、地址</li></ul> |
| 关联用户故事 | US-MVP-16 6 页面咨询入口嵌入 · US-MVP-14 商品卡片 · US-MVP-13 订单卡片 |

#### U-03 离线留言

| 项 | 内容 |
|----|------|
| 页面路径 | `prototype/user-offline.html` |
| 功能描述 | 当客服全部离线或非工作时段时，用户进入会话看到离线提示，可提交留言表单，客服上线后跟进处理 |
| 核心交互 | <ul><li>页面顶部展示「客服当前不在线，请留下您的问题」提示横条</li><li>留言表单：问题分类（下拉：售前/售后/物流/退款/账户/其他）、问题描述（多行文本，必填）、联系方式（手机号/邮箱，必填）、图片附件（可选，最多 6 张）</li><li>提交后展示「留言成功，客服将在工作时间内回复」成功页，留言进入 A-10 留言管理列表</li><li>已登录用户自动填充联系方式，无需重复输入</li></ul> |
| 关联用户故事 | US-MVP-17 离线留言提交 · US-MVP-18 离线反馈渠道 |

#### U-04 服务评价

| 项 | 内容 |
|----|------|
| 页面路径 | `prototype/user-rating.html` |
| 功能描述 | 会话结束后弹出评价页，用户对客服服务进行星级评分、标签反馈与文字评价 |
| 核心交互 | <ul><li>5 星星级评分（默认 5 星，可点选 1-5 星）</li><li>预设评价标签：响应快 / 态度好 / 专业 / 解决了问题 / 回复慢 / 态度差 / 没解决（正向绿底 + 负向红底，可多选）</li><li>文字评价（选填，最多 200 字，带字数计数）</li><li>「匿名评价」开关</li><li>提交后数据写入会话 `rate` 字段并聚合至 A-09 评价管理</li><li>评价提交成功后展示「感谢您的评价」并关闭会话</li></ul> |
| 关联用户故事 | US-MVP-19 服务评价 UI · US-MVP-20 评价提交 |

#### U-05 FAQ 列表

| 项 | 内容 |
|----|------|
| 页面路径 | `prototype/user-faq.html` |
| 功能描述 | 常见问题自助解决入口，支持分类浏览、关键词搜索与热门问题推荐，降低人工咨询量 |
| 核心交互 | <ul><li>顶部搜索框，输入关键词实时匹配 FAQ 条目（来自 A-07 知识库）</li><li>分类 Tab：售前咨询 / 物流配送 / 售后退换 / 支付问题 / 账户会员 / 优惠活动</li><li>热门问题列表（点击展开/收起答案，支持富文本与图片）</li><li>FAQ 底部「仍未解决？联系在线客服」按钮，点击跳转 U-01 聊天页并携带 `entry_tag: help` + `faq_category`</li></ul> |
| 关联用户故事 | US-P2-01 FAQ 快捷问题 · US-MVP-16 帮助中心入口兜底 |

> 用户端 8 个逻辑页面 = U-01 + U-02（6 子场景）+ U-03 + U-04 + U-05。

### 2. 状态流转

#### 会话状态机（`customer_chat_sessions.status`）

```
wait  ──客服接起──▶  accept  ──正常结束──▶  close
  │                    │
  │                    ├──超时/客服离线──▶  cancel
  │                    ├──用户退出──▶  cancel
  │                    └──转接──▶  accept（新客服）
  │
  └──超时未接──▶  cancel
```

| 状态 | 值 | 触发条件 |
|------|----|----------|
| wait | 0 | 用户发起会话，进入排队 |
| accept | 1 | 客服接起 / 转接成功 |
| close | 2 | 任一方主动关闭 / 空闲超时自动关闭 |
| cancel | 3 | 用户退出 / 超时未接 |

#### 客服在线状态

| 状态 | 含义 | 行为 |
|------|------|------|
| online | 在线 | 自动接起（若 `is_auto_accept=1`）或接收新会话提醒 |
| busy | 忙碌 | 不自动接起，仅手动接起 |
| offline | 离线 | 新会话进入排队或触发离线留言 / AI 兜底 |

#### 消息来源色标（`customer_chat_messages.source`）

| 来源 | 值 | 气泡样式 | 对齐 |
|------|----|----------|------|
| 用户 | 0 | 绿底 #95ec69 | 右 |
| 客服 | 1 | 白底带边框 | 左 |
| 系统 | 2 | 半透明黑底 | 居中 |
| AI | 3 | 紫底 #f9f0ff / 带「AI」角标 | 左 |

### 4. 卡片交互说明

#### 商品卡片（`product_card`）

- **结构**：商品主图 + 名称 + 规格 + 价格 + 「查看商品」CTA
- **用户端**：从商品详情页咨询入口自动发送；卡片 CTA 跳转商品详情页
- **管理端**：聊天窗口内展示，客服点击 CTA 在新标签打开商城商品页

#### 订单卡片（`order_card`）

- **结构**：订单号 + 商品缩略图列表 + 订单状态标签 + 金额 + 「查看订单」CTA
- **用户端**：从订单详情页咨询入口自动发送
- **管理端**：展示并可点击 CTA 打开 OMS 订单详情；侧栏「查看订单」同步展示

#### 优惠券卡片（`coupon_card`）

- **结构**：券面额 + 适用范围 + 有效期 + 「立即领取」CTA
- **下发方**：客服主动推送或系统自动营销
- **用户端**：点击 CTA 一键领取并跳转可用商品列表
