## Locked Decisions（必须实现）

- **D-01: 全量原型覆盖**
  - 原因: 用户选择覆盖 1/2/3 期全部页面（20+）
  - 影响: 生成完整原型网站，含 index 导航页 + 分类页面

- **D-02: HTML 原型格式**
  - 原因: 用户选择可预览的 HTML
  - 影响: 每个页面为独立 HTML 文件，含交互说明文档

- **D-03: 统一设计风格**
  - 原因: 多页面需保持视觉一致
  - 影响: 生成共享 CSS（prototype/styles.css），管理端用 Ant Design 风格，用户端用移动端风格
