## 4. 关键路径分析

### 4.1 最长路径

```
US-MVP-11 (知识库) → US-MVP-24 (FAQ 快捷问题) → W6-7 集成测试 → 上线
```

知识库是 FAQ 快捷问题的前置依赖，FAQ 是最后完成的开发项，决定了集成测试的开始时间。

### 4.2 瓶颈路径

```
US-MVP-20 (留言提交) → US-MVP-06 (留言管理)
US-MVP-21 (评价 UI) → US-MVP-13 (评价管理) → US-MVP-10 (服务数据)
```

这些串行依赖链较长，需要严格按顺序开发。

### 4.3 可并行路径

以下功能无依赖关系，可并行开发：

| 前端 W1-2 | US-MVP-02 管理端页面 + US-MVP-04 管理端页面 | 吕道远（前端） |
| 后端 W3-4 | US-MVP-11 知识库后端 | 贺远航 |
