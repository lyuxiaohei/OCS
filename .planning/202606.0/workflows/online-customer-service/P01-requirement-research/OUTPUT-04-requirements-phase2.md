## 1. 会话管理增强（5 项）

### US-P2-01: 消息预显

| 字段 | 内容 |
|------|------|
| **ID** | US-P2-01 |
| **名称** | 消息预显（输入状态提示） |
| **角色** | 客服人员 / 终端用户 |
| **用户故事** | 作为客服人员，我希望看到用户正在输入的消息内容实时预览，以便提前准备回复提高响应速度 |
| **验收标准** | AC1: 用户开始输入时，客服端显示实时输入内容（延迟 < 500ms）<br>AC2: 用户停止输入 3 秒后预显消失<br>AC3: 仅客服端可看到预显，其他用户不可见<br>AC4: 可通过开关控制是否启用 |
| **优先级** | P1-H |
| **期次** | 2期 |
| **依赖** | WebSocket 新增 `typing` action |
| **技术备注** | 新增 WebSocket `typing` action；前端 debounce 300ms 发送；服务端广播给对应客服 |
