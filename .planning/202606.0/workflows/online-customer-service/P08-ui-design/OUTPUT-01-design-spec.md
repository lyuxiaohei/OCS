## 1. 设计原则

### 1.1 总体原则

| 原则 | 说明 |
|------|------|
| **一致性** | 跨端视觉语言统一——品牌色、圆角、阴影、动效在管理端与用户端使用同一套设计令牌 |
| **清晰性** | 信息层级分明，标题/正文/辅助文字三段式对比，避免视觉噪音 |
| **高效性** | 管理端追求信息密度与操作效率；用户端追求单手可达与零学习成本 |
| **容错性** | 关键操作（转接、关闭会话、踢出）须有二次确认；错误状态有明确反馈 |
| **可访问性** | 文字对比度满足 WCAG AA（≥4.5:1）；点击区域最小 36×36px |

### 1.2 管理端原则

- 遵循 **Ant Design v5** 设计规范，复用其组件语义与交互模式
- 专业、高效、信息密度适中——客服人员日均处理 80+ 会话，减少点击次数与视线移动
- 全屏工作台为核心场景，三栏布局（会话列表 / 聊天区 / 客户信息）一屏完成接待

### 1.3 用户端原则

- 移动端优先（375px 基准），支持微信小程序与 H5
- 简洁、亲和、单手操作友好——核心操作集中在屏幕下方 1/3 区域
- 对话即界面：以聊天气泡为主，富媒体卡片（订单/商品/优惠券）为辅

### 2.5 图标系统

| 端 | 图标库 | 规格 | 风格 |
|----|--------|------|------|
| 管理端 | `@ant-design/icons` | 16px（行内）/ 20px（导航）/ 32px（空状态） | 线性（outlined）为主，填充（filled）用于激活态 |

#### 图标规范

- 用户端所有可点击图标的最小命中区域为 **36×36px**（视觉 24px + 透明 padding 6px）
- 颜色随文字色继承（`currentColor`），便于主题切换
- 状态图标：在线（绿点 6px）/ 离线（灰点 `#bfbfbf`）/ 等待（黄点），使用 `.status-badge::before` 圆点方案

## 3. 布局规范

### 3.1 管理端布局

#### 3.1.1 整体框架（Layout）

```
┌─────────────────────────────────────────────────────────┐
│ Sidebar(208) │ Header(56, sticky)                       │
│              ├──────────────────────────────────────────┤
│  Logo(56)    │                                          │
│  Menu items  │           Content (flex-1, padding 24)    │
│  ...         │                                          │
│  (深色 #001529)│                                        │
└─────────────────────────────────────────────────────────┘
```

| 区域 | 尺寸 | 说明 |
|------|------|------|
| 侧栏 Sidebar | 宽 208px，背景 `#001529`，文字 `rgba(255,255,255,0.85)` | Logo 区高 56px；菜单项 padding `10px 24px`；激活态背景 `#1677ff` |
| 顶部 Header | 高 56px，背景 `#fff`，底边 `1px solid #f0f0f0` | sticky 定位；左侧 breadcrumb（13px `#8c8c8c`），右侧用户信息 |
| 内容区 Content | flex-1，padding 24px，overflow-y auto | 页面级背景 `#f0f2f5` |

> **P07 修复（D-04）**：CLAUDE.md 记载 Header 为 64px，原型实现为 56px。本规范统一为 **56px**（与 P06 原型一致，更贴合 Ant Design Pro 默认），如后续业务需要更大操作区可上调至 64px。

#### 3.1.2 工作台三栏（Chat 页面专用）

```
┌──────────────┬────────────────────────┬───────────────┐
│ 会话列表 280  │ 聊天区 flex-1           │ 客户信息 320   │
│ session-list │ chat-messages / input   │ customer-info │
└──────────────┴────────────────────────┴───────────────┘
```

| 列 | 宽度 | 内容 |
|----|------|------|
| 会话列表 | 280px | 搜索框 + 会话项（头像 40px + 昵称 + 最后消息 + 时间 + 未读 badge）；选中态 `#e6f4ff` + 左 3px `#1677ff` 边 |
| 聊天区 | flex-1 | 顶部会话标题栏 + 消息流（flex-1, overflow）+ 输入区（含快捷回复、富媒体入口） |
| 客户信息 | 320px | 用户基础信息 + 行为/交易/服务数据 + 标签 + 历史会话入口 |

> 在 1280px 屏宽下三栏总宽 = 280 + flex + 320，聊天区最小可用宽 ≈ 600px；屏宽 < 1200px 时客户信息列可折叠为抽屉。

### 3.2 用户端布局

#### 3.2.1 移动端容器（基准 375px）

```
┌──────────────────────────────┐
│ 顶部 Header 56px             │  ← 返回 + 标题(居中) + 操作图标
├──────────────────────────────┤
│                              │
│  消息区 flex-1 (overflow)     │  ← padding 12px, gap 10px
│  背景 #ededed                │
│                              │
├──────────────────────────────┤
│ 输入区 56px                  │  ← 图标 + 胶囊输入框(36px高) + 发送
└──────────────────────────────┘
```

| 区域 | 尺寸 | 说明 |
|------|------|------|
| Header | 高 56px，背景 `#f7f7f7`，底边 `1px solid #dcdcdc` | 左返回箭头 22px，标题居中 16px/600，右操作图标 20px |
| 消息区 | flex-1，padding 12px，gap 10px，背景 `#ededed` | 气泡最大宽 72%，用户右对齐，客服左对齐，系统居中 |
| 输入区 | 高 56px，背景 `#f7f7f7`，顶边 `1px solid #dcdcdc` | 输入框胶囊形高 36px / radius 18px / 边框 `#ddd` |

> CLAUDE.md 提及「标题栏 44px」，原型采用 56px。本规范以 **56px** 为准（容纳 22px 返回箭头 + 16px 标题的舒适高度）；如需严格对齐小程序原生导航栏，可在 H5 用 44px、小程序使用原生导航。

## 4. 响应式策略

### 4.1 管理端

| 断点 | 行为 |
|------|------|
| ≥ 1920px | 工作台三栏均展开，dashboard 支持 4 列网格 |
| 1440–1920px（推荐） | 三栏展开，dashboard 3–4 列 |
| 1280–1440px（最小支持） | 三栏展开，聊天区紧凑；dashboard 降为 2 列 |
| < 1280px | 不支持，提示用户使用更大屏幕；客户信息列折叠为抽屉 |

- Dashboard 网格断点：`@media (max-width: 1200px)` 时 `.grid-4` → 2 列，`.grid-3` → 2 列（已在 styles.css 实现）
- 侧栏支持折叠至 48px（仅图标），供低分辨率场景

### 4.2 用户端

| 场景 | 宽度 | 策略 |
|------|------|------|
| iPhone SE | 375px | 基准设计宽度 |
| 主流 iPhone / 安卓 | 390–414px | 等比自适应（rem / rpx） |
| 平板 H5 | ≥ 768px | 聊天容器居中，最大宽 480px，两侧留白 |
| 微信小程序 | 100% | 使用 `rpx`（750 设计稿基准，即 375pt = 750rpx） |

- 用户端不响应桌面宽屏，始终以移动布局居中展示

## 5. 动效规范

### 5.1 通用过渡

| 场景 | 时长 | 缓动 | 属性 |
|------|------|------|------|
| 按钮 Hover / Active | 0.2s | `ease-in-out` | background-color / border-color / color |
| 菜单项 / 会话项 Hover | 0.2s | `ease-in-out` | background-color |
| 颜色切换 | 0.2s | `ease-in-out` | color / fill |

### 5.2 弹出与浮层

| 场景 | 时长 | 缓动 | 效果 |
|------|------|------|------|
| Modal / Drawer 进入 | 0.15s | `ease-out` | scale(0.96→1) + fade |
| Modal / Drawer 离开 | 0.15s | `ease-in` | scale(1→0.96) + fade |
| Dropdown / Tooltip | 0.1s | `ease-out` | fade + 轻微 translateY(4→0) |

### 5.3 消息动效（用户端 / 管理端聊天区）

| 场景 | 时长 | 缓动 | 效果 |
|------|------|------|------|
| 新消息出现 | 0.2s | `ease-out` | 从对应一侧 slide-in + fade |
| 打字指示器（"对方正在输入..."） | 0.3s 循环 | `ease-in-out` | 三点呼吸/跳动 |
| 消息发送中（loading） | — | — | 输入区禁用 + 发送按钮转圈 |
| 未读 badge 数字变化 | 0.15s | `ease-out` | scale 弹跳 |

### 5.4 动效原则

- 所有动效时长 ≤ 0.3s，避免阻塞操作感知
- 尊重用户「减少动态」系统设置（`@media (prefers-reduced-motion: reduce)` 时禁用非必要动画）
- 加载状态优先使用骨架屏（Skeleton），避免空白闪烁
